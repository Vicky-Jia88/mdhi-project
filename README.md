# MDHI Projects page

This repository is a standalone, editable copy of the MDHI Projects page captured from:

https://mdhiglobal.com/mdhiproje.html

## Publish with GitHub Pages

1. Upload everything in this folder to the root of the `mdhi-project` repository.
2. In GitHub, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and `/ (root)`, then save.

The page uses only relative paths for its own CSS, JavaScript, fonts, and images. Navigation items for pages not included in this one-page repository link back to the original MDHI website.

## Main editable files

- `index.html` — page content and modal markup
- `css/style.css` — the original site's main styles
- `css/responsive-leyouts.css` — responsive styles
- `js/main.js` — small GitHub Pages navigation helper
- `images/` — logo, favicon, and project graphics

The original site is not modified by this copy.
